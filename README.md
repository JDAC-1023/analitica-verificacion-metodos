# Sistema de Analítica de Datos - Verificación y Métodos de Calibración

## Propósito del Proyecto
Este proyecto académico tiene como objetivo desarrollar un entorno analítico para la verificación y validación de métodos de calibración, estructurando una arquitectura modular, escalable y mantenible.

## Participantes

## Herramientas y Tecnologías
- **Lenguaje:** Python 3.12+
- **IDE:** Visual Studio Code
- **Control de Versiones:** Git / GitHub
- **Integración Continua (CI):** GitHub Actions
- **Pruebas Unitarias:** pytest
- **Interfaz de Usuario:** Streamlit
- **Base de Datos (Previsto):** Supabase

## Estado Actual
El proyecto se encuentra en la **Fase 1: Preparación y verificación del entorno de desarrollo**. 
> **Nota:** En este punto el repositorio cuenta con la estructura base, integración continua funcional y la aplicación inicial de Streamlit. Todavía **NO** existe el motor estadístico ni la parametrización experimental, los cuales serán desarrollados en fases posteriores.
